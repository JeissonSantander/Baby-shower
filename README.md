# 🧸 Baby Shower — Invitación Web

Invitación digital estática hecha con HTML, CSS y JavaScript.

## 📁 Estructura

- `index.html` — contenido de la invitación.
- `styles.css` — diseño y responsive.
- `script.js` — cuenta regresiva y animaciones.
- `assets/` — fotos, música e imágenes propias.

## ✏️ Datos que debes cambiar

En `index.html` busca y reemplaza:

- Fecha del evento.
- Hora.
- Lugar.
- Nombre del bebé / futuros papás.
- Número de WhatsApp.
- Enlace de Google Maps.
- Enlace de lista de regalos.

En `script.js` cambia:

```js
const eventDate = new Date("2026-10-25T16:00:00");
```

por la fecha y hora reales.

## 🚀 Publicar en GitHub Pages

1. Crea un repositorio público en GitHub.
2. Sube todos los archivos manteniendo la estructura de carpetas.
3. Ve a `Settings` → `Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda.
7. GitHub generará una dirección similar a:

`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

## 📱 Importante

Prueba primero la invitación en el celular antes de compartirla.

No necesitas servidor, base de datos ni backend para esta versión.
